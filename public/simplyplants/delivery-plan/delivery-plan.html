SimplyPlants 12-Week MVP Delivery Plan

Problem Statement

Launch SimplyPlants e-commerce store with 13,130 SKUs across 47 PLPs (of 440 total) using Magento 2.4.8 + Hyva theme with Nike-style URL filtering. 12-week delivery (Feb 2 → Apr 23, 2026). Week 1 is setup, refinement and planning. UAT starts Apr 6, GO LIVE target May 1, 2026.

Scope In

  • Fresh Magento 2.4.8 installation with Hyva + Hyva Checkout
  • 47 PLPs (16 L1 + 31 L2 categories) for initial launch
  • Custom URL routing with 5-char filter codes
  • 133 filter codes registry
  • 16 HIGH priority product attributes (MVP-critical only)
  • Nike-style 3-section sidebar (Hot Keys DEFERRED)
  • Product badge system (7 badge types)
  • Filter persistence across categories
  • Mobile responsive with drawer sidebar
  • Performance optimization for 13K SKUs (LCP ≤2500ms)
  • WCAG 2.1 AA accessibility compliance
  • E2E testing with Playwright

Scope Out

  • Hot Keys quick-filter presets (DEFERRED by team decision)
  • Remaining 393 PLPs (add in Phase 1.5 post-launch)
  • MEDIUM/LOW priority attributes (37 attributes deferred)
  • Advanced features (grouped/bundle products, personalization)
